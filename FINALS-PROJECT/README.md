# Gaming & Mental Health — Data Analysis Report

A collaborative data science project analyzing the relationship between 
gaming habits and mental health indicators.

## Dataset
- **Source:** Gaming and Mental Health Behavioral Dataset
- **Rows:** ~1,000,000
- **Features:** 40 variables
- **Analysis sample:** 10,000 random rows

## How to Run
1. Clone this repository
2. Place `gaming_mental_health.csv` inside the `/data/` folder
3. Start a local server:
   ```
   python -m http.server 8000
   ```
4. Open `http://localhost:8000` in your browser
